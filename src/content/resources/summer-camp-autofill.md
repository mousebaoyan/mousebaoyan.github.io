## 资源简介

各院校报名系统的表单结构不同，但通常包含姓名、本科院校、学业成绩与联系方式等相同信息。

该扩展支持保存报名资料，并在报名页面识别和填写对应字段，减少重复录入。

## 两种识别模式

**关键词规则模式**（默认，免费，离线）
通过内置关键词匹配表单字段，资料仅保存在本地，识别过程无需联网。未识别字段以红色标记，需手动补全。

**AI 模式**（可选，需 DeepSeek API Key）

通过 AI 分析页面字段，辅助识别下拉选项及非标准命名等规则模式难以匹配的内容。

启用后，页面字段名与个人资料将发送至 DeepSeek。不希望向第三方发送资料时，可使用关键词规则模式。

## 使用流程

1. 按照项目 README 安装浏览器扩展
2. 打开扩展，在「设置我的资料」中录入并保存报名信息
3. 进入报名页面，点击右下角「📝 一键填充」
4. 补全红框标注的未识别字段，核对所有信息后提交

## 使用注意事项

- 照片上传、验证码、登录密码需手动操作
- 提交前应核对身份证号、手机号、排名等关键信息
- 两种模式均需人工确认填写结果
