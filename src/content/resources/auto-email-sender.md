## 资源简介

导师联系涉及邮箱查询、申请材料整理、邮件发送与回复记录等环节。

AutoEmailSender 集成导师信息采集、匹配分析、草稿生成、定时批量发送与回复追踪功能，支持在同一应用中管理导师联系流程。

> 收件人、邮件内容与发送时间由使用者确认。

## 主要功能

| 功能         | 说明                                           |
| ------------ | ---------------------------------------------- |
| 智能抓取     | 从学校官网整理导师信息，减少手动复制和表格维护 |
| 匹配度分析   | 结合申请材料与导师资料，辅助确定联系优先级     |
| 导师标签     | 自定义标签标记和筛选导师，支持导入导出         |
| 定时批量发送 | 草稿确认后立即发送，或设置发送时间窗口         |
| 回复追踪     | 自动检测导师回复并记录联系状态                 |
